# Dominó a 100

Dominó por parejas a 100 puntos, con coach, lecciones por niveles, contrarreloj de conteo, estadísticas y logros. Funciona sin internet después de la primera visita.

**Jugar:** https://isaachm11.github.io/domino-a-100/

## Instalar en iPhone
1. Abre el enlace en Safari.
2. Toca Compartir → Agregar a pantalla de inicio.
3. Ábrela una vez con internet; después funciona sin conexión.

## Instalar en Android
Abre el enlace en Chrome y toca "Instalar app" (o menú ⋮ → Agregar a la pantalla principal).
